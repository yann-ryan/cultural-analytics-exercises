Data Analysis 2: Practice Exercises

filter, mutate, summarise, and grouping

These exercises let you practise the verbs from the Data Analysis 2 part of the course book: filter(), mutate(), summarise(), and group_by(). They all use the same titanic_df dataset from the course.

Write your code in the box, then click Run Code to see the result and get feedback.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: filter() with one condition

Filter titanic_df to keep only the female passengers.

Use filter() with sex == 'female'. Remember filter needs a double equals sign to check equality.

titanic_df |> filter(sex == 'female') 
titanic_df |> filter(sex == 'female')

Exercise 2: filter() with a numeric condition

Filter titanic_df to keep only passengers under 18 years old.

Use the < comparison on the age column.

titanic_df |> filter(age < 18) 
titanic_df |> filter(age < 18)

Exercise 3: combining conditions with &

Filter titanic_df to keep only passengers who were in first class AND survived.

pclass == 1 for first class, survived == 1 for survivors, joined with &.

titanic_df |> filter(pclass == 1 & survived == 1) 
titanic_df |> filter(pclass == 1 & survived == 1)

Exercise 4: combining conditions with |

Filter titanic_df to keep passengers where either the fare was more than 100, or they were in first class.

Use | instead of & to mean “either condition can be true”.

titanic_df |> filter(fare > 100 | pclass == 1) 
titanic_df |> filter(fare > 100 | pclass == 1)

Exercise 5: %in%

Filter titanic_df to keep only passengers who embarked at Cherbourg (C) or Queenstown (Q).

Use embarked %in% c('C', 'Q').

titanic_df |> filter(embarked %in% c('C', 'Q')) 
titanic_df |> filter(embarked %in% c('C', 'Q'))

Exercise 6: mutate()

Create a new column called price_today, equal to fare multiplied by 78.17 (an approximate inflation adjustment).

mutate(price_today = fare * 78.17)

titanic_df |> mutate(price_today = fare * 78.17) 
titanic_df |> mutate(price_today = fare * 78.17)

Exercise 7: mutate() with if_else()

Create a new column called status, which is 'child' if age is less than 18, and 'adult' otherwise.

mutate(status = if_else(age < 18, 'child', 'adult'))

titanic_df |> mutate(status = if_else(age < 18, 'child', 'adult')) 
titanic_df |> mutate(status = if_else(age < 18, 'child', 'adult'))

Exercise 8: summarise()

In a single summarise(), calculate the average (mean) age, calling it mean_age, and the maximum fare, calling it max_fare.

summarise(mean_age = mean(age, na.rm = TRUE), max_fare = max(fare, na.rm = TRUE)). The na.rm = TRUE matters here, since some ages are missing.

titanic_df |> summarise(mean_age = mean(age, na.rm = TRUE), max_fare = max(fare, na.rm = TRUE)) 
titanic_df |> summarise(mean_age = mean(age, na.rm = TRUE), max_fare = max(fare, na.rm = TRUE))

Stretch exercise 9: group_by() and summarise()

For each passenger class (pclass), calculate the total number of passengers (call it total) and the average fare paid (call it avg_fare).

group_by(pclass), then summarise(total = n(), avg_fare = mean(fare, na.rm = TRUE)).

titanic_df |> group_by(pclass) |> summarise(total = n(), avg_fare = mean(fare, na.rm = TRUE)) 
titanic_df |>
  group_by(pclass) |>
  summarise(total = n(), avg_fare = mean(fare, na.rm = TRUE))

Stretch exercise 10: mutate() with case_when()

Create a new column called status, with three categories based on age: 'child' for under 13, 'teenager' for 13 up to (but not including) 20, and 'adult' for 20 and over.

case_when() takes a series of condition ~ value pairs, checked in order:

mutate(status = case_when(
  age < 13 ~ "child",
  age < 20 ~ "teenager",
  age >= 20 ~ "adult"
))

Because case_when() checks each condition in order and stops at the first match, you don’t need to repeat age >= 13 for the teenager row.

titanic_df |> mutate(status = case_when( age < 13 ~ "child", age < 20 ~ "teenager", age >= 20 ~ "adult" )) 
titanic_df |>
  mutate(status = case_when(
    age < 13 ~ "child",
    age < 20 ~ "teenager",
    age >= 20 ~ "adult"
  ))
