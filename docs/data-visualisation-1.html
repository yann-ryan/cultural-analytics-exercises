Data Visualisation 1: Practice Exercises

ggplot2 basics and chart types

These exercises practise building charts with ggplot2, from the Data Visualisation 1 part of the course book. They use the titanic_df and Nobel Prize datasets from the course.

Write your code in the box, then click Run Code to see the plot and get feedback. Unlike the earlier exercises, these are checked by comparing your code to the model solution (rather than the result), so it’s fine if the plot looks right but the feedback still points out something specific to fix - it’s checking things like which variable you mapped to which aesthetic.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: a basic bar chart

Using the pre-summarised df (a count of passengers by sex), build a bar chart with sex on the x axis and n on the y axis.

The geom for a bar chart made from already-summarised data is geom_col().

ggplot(data = df, aes(x = sex, y = n)) + geom_col() 
ggplot(data = df, aes(x = sex, y = n)) +
  geom_col()

Exercise 2: a scatterplot

Using nobel_summary (one row per prize category), make a scatterplot with avg_age on the x axis and pct_female on the y axis.

Scatterplots use geom_point().

ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female)) + geom_point() 
ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female)) +
  geom_point()

Exercise 3: mapping size

Copy the scatterplot from exercise 2, and additionally map the n column (the number of laureates) to the size aesthetic.

Add size = n inside the aes().

ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, size = n)) + geom_point() 
ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, size = n)) +
  geom_point()

Exercise 4: mapping colour

Copy the scatterplot from exercise 2 again, this time mapping the category column to colour.

Add color = category inside the aes(). (Either color or colour works in ggplot2.)

ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, color = category)) + geom_point() 
ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, color = category)) +
  geom_point()

Exercise 5: a line chart

Using physics_by_decade (already summarised to one row per decade), make a line chart with decade on the x axis and n on the y axis.

Line charts use geom_line().

ggplot(data = physics_by_decade, aes(x = decade, y = n)) + geom_line() 
ggplot(data = physics_by_decade, aes(x = decade, y = n)) +
  geom_line()

Exercise 6: a histogram

Using nobel_df, plot the distribution of age_at_award.

Histograms only need one variable mapped (x), and use geom_histogram().

ggplot(data = nobel_df, aes(x = age_at_award)) + geom_histogram() 
ggplot(data = nobel_df, aes(x = age_at_award)) +
  geom_histogram()

Exercise 7: a boxplot

Using nobel_df, make a boxplot of age_at_award for each category. You’ll need to map category to both x and group, and age_at_award to y.

Boxplots use geom_boxplot().

ggplot(data = nobel_df, aes(x = category, y = age_at_award, group = category)) + geom_boxplot() 
ggplot(data = nobel_df, aes(x = category, y = age_at_award, group = category)) +
  geom_boxplot()

Exercise 8: fill mapped to a category

df2 counts passengers by sex and embarked. Build a bar chart with sex on the x axis, n on the y axis, and embarked mapped to fill.

The geom is the same as exercise 1 - only the aesthetics change.

ggplot(data = df2, aes(x = sex, y = n, fill = embarked)) + geom_col() 
ggplot(data = df2, aes(x = sex, y = n, fill = embarked)) +
  geom_col()

Stretch exercise 9: two aesthetics at once

Using nobel_summary, make a scatterplot of avg_age (x) against pct_female (y), mapping both size to n and color to category in the same chart.

This combines exercises 3 and 4 - both size = n and color = category go inside the same aes().

ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() 
ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point()

Stretch exercise 10: mapped fill, fixed outline

Some point shapes (21 to 25) have a separate outline colour and fill colour. Using nobel_summary, build a scatterplot of avg_age (x) against pct_female (y), with category mapped to fill. Then, in the geom_point() layer (not inside aes()), set shape to 21 and color to "black", to give every point a fixed black outline.

fill is mapped to data, so it goes inside aes(). shape and color are both set to fixed values here, so they go outside aes(), as arguments to geom_point() directly.

ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, fill = category)) + geom_point(shape = 21, color = "black") 
ggplot(data = nobel_summary, aes(x = avg_age, y = pct_female, fill = category)) +
  geom_point(shape = 21, color = "black")
