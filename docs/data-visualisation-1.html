Data Visualisation 1: Practice Exercises

ggplot2 basics and chart types

These exercises practise building charts with ggplot2, from the Data Visualisation 1 part of the course book. They use the titanic_df and gapminder_df datasets from the course.

Write your code in the box, then click Run Code to see the plot and get feedback. Unlike the earlier exercises, these are checked by comparing your code to the model solution (rather than the result), so it’s fine if the plot looks right but the feedback still points out something specific to fix - it’s checking things like which variable you mapped to which aesthetic.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: a basic bar chart

Using the pre-summarised df (a count of passengers by sex), build a bar chart with sex on the x axis and n on the y axis.

The geom for a bar chart made from already-summarised data is geom_col().

ggplot(data = df, aes(x = sex, y = n)) + geom_col() 
ggplot(data = df, aes(x = sex, y = n)) +
  geom_col()

Exercise 2: a scatterplot

Using gapminder_df (already filtered to the year 2007), make a scatterplot with lifeExp on the x axis and gdpPercap on the y axis.

Scatterplots use geom_point().

ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap)) + geom_point() 
ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap)) +
  geom_point()

Exercise 3: mapping size

Copy the scatterplot from exercise 2, and additionally map the pop column to the size aesthetic.

Add size = pop inside the aes().

ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, size = pop)) + geom_point() 
ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, size = pop)) +
  geom_point()

Exercise 4: mapping colour

Copy the scatterplot from exercise 2 again, this time mapping the continent column to colour.

Add color = continent inside the aes(). (Either color or colour works in ggplot2.)

ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, color = continent)) + geom_point() 
ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, color = continent)) +
  geom_point()

Exercise 5: a line chart

Using netherlands_df (already filtered to just the Netherlands), make a line chart with year on the x axis and gdpPercap on the y axis.

Line charts use geom_line().

ggplot(data = netherlands_df, aes(x = year, y = gdpPercap)) + geom_line() 
ggplot(data = netherlands_df, aes(x = year, y = gdpPercap)) +
  geom_line()

Exercise 6: a histogram

Using gapminder_2007, plot the distribution of gdpPercap.

Histograms only need one variable mapped (x), and use geom_histogram().

ggplot(data = gapminder_2007, aes(x = gdpPercap)) + geom_histogram() 
ggplot(data = gapminder_2007, aes(x = gdpPercap)) +
  geom_histogram()

Exercise 7: a boxplot

Using gapminder_2007, make a boxplot of lifeExp for each continent. You’ll need to map continent to both x and group, and lifeExp to y.

Boxplots use geom_boxplot().

ggplot(data = gapminder_2007, aes(x = continent, y = lifeExp, group = continent)) + geom_boxplot() 
ggplot(data = gapminder_2007, aes(x = continent, y = lifeExp, group = continent)) +
  geom_boxplot()

Exercise 8: fill mapped to a category

df2 counts passengers by sex and embarked. Build a bar chart with sex on the x axis, n on the y axis, and embarked mapped to fill.

The geom is the same as exercise 1 - only the aesthetics change.

ggplot(data = df2, aes(x = sex, y = n, fill = embarked)) + geom_col() 
ggplot(data = df2, aes(x = sex, y = n, fill = embarked)) +
  geom_col()

Stretch exercise 9: two aesthetics at once

Using gapminder_2007, make a scatterplot of lifeExp (x) against gdpPercap (y), mapping both size to pop and color to continent in the same chart.

This combines exercises 3 and 4 - both size = pop and color = continent go inside the same aes().

ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, size = pop, color = continent)) + geom_point() 
ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, size = pop, color = continent)) +
  geom_point()

Stretch exercise 10: mapped fill, fixed outline

Some point shapes (21 to 25) have a separate outline colour and fill colour. Using gapminder_2007, build a scatterplot of lifeExp (x) against gdpPercap (y), with continent mapped to fill. Then, in the geom_point() layer (not inside aes()), set shape to 21 and color to "black", to give every point a fixed black outline.

fill is mapped to data, so it goes inside aes(). shape and color are both set to fixed values here, so they go outside aes(), as arguments to geom_point() directly.

ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, fill = continent)) + geom_point(shape = 21, color = "black") 
ggplot(data = gapminder_2007, aes(x = lifeExp, y = gdpPercap, fill = continent)) +
  geom_point(shape = 21, color = "black")
