Data Analysis 1: Practice Exercises

select, slice, arrange, and pipes

These exercises let you practise the verbs from the Data Analysis 1 part of the course book: select(), slice(), arrange(), and the pipe |>. They all use the same titanic_df dataset from the course.

Write your code in the box, then click Run Code to see the result and get feedback.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: select()

Select the name, age, and sex columns from titanic_df.

Use select(), and list the three column names separated by commas.

titanic_df |> select(name, age, sex) 
titanic_df |> select(name, age, sex)

Exercise 2: deselecting a column

Select every column from titanic_df except cabin.

Put a minus sign directly in front of the column name inside select().

titanic_df |> select(-cabin) 
titanic_df |> select(-cabin)

Exercise 3: starts_with()

Select all the columns whose names start with the letter s.

Use the tidyselect helper starts_with() inside select().

titanic_df |> select(starts_with("s")) 
titanic_df |> select(starts_with("s"))

Exercise 4: slice()

Select the first 10 rows of titanic_df.

slice() takes a range like 1:10.

titanic_df |> slice(1:10) 
titanic_df |> slice(1:10)

Exercise 5: slice_max()

Find the 5 oldest passengers in the dataset.

You’ll need slice_max(), with order_by = age and n = 5.

titanic_df |> slice_max(order_by = age, n = 5) 
titanic_df |> slice_max(order_by = age, n = 5)

Exercise 6: slice_min()

Find the 5 passengers who paid the least fare.

slice_min() works just like slice_max(), but the other way round. Use order_by = fare and n = 5.

titanic_df |> slice_min(order_by = fare, n = 5) 
titanic_df |> slice_min(order_by = fare, n = 5)

Exercise 7: arrange(), ascending

Sort titanic_df by age, youngest first.

arrange() sorts ascending (smallest first) by default - you don’t need any extra symbols here.

titanic_df |> arrange(age) 
titanic_df |> arrange(age)

Exercise 8: arrange(), descending

Sort titanic_df by fare, from highest to lowest.

To sort descending, put a minus sign in front of the column name.

titanic_df |> arrange(-fare) 
titanic_df |> arrange(-fare)

Stretch exercise 9: combining verbs with the pipe

In one piped sequence, starting from titanic_df: keep only the name, pclass, and fare columns, and sort the result by fare, from highest to lowest.

You’ll need two verbs chained together with |>: one to keep the three columns, and one to sort them. The order you do them in doesn’t matter here.

titanic_df |> select(name, pclass, fare) |> arrange(-fare) 
titanic_df |>
  select(name, pclass, fare) |>
  arrange(-fare)

Stretch exercise 10: a longer pipeline

Starting from titanic_df, in one piped sequence: find the 10 passengers who paid the highest fare, keep only the name, pclass, and fare columns, then sort the result first by pclass (ascending), and then by fare (descending) within each class.

Three verbs this time: slice_max() to get the top 10 fares, select() to keep the three columns, and arrange() with two column names to sort by class then fare. Remember you can list more than one column in arrange(), separated by a comma.

titanic_df |> slice_max(order_by = fare, n = 10) |> select(name, pclass, fare) |> arrange(pclass, -fare) 
titanic_df |>
  slice_max(order_by = fare, n = 10) |>
  select(name, pclass, fare) |>
  arrange(pclass, -fare)
