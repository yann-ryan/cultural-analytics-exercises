Data Visualisation 3: Practice Exercises

titles, themes, and annotations

These exercises practise titles, themes, and annotations from the Data Visualisation 3 part of the course book, using the Nobel Prize dataset.

Like the other ggplot2 exercises, these are checked by comparing your code to a model solution, so the feedback will point you to a specific part of your code to fix.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: adding a title

Starting from the chart below, add a title reading "Age and Gender\nat the Nobel Prize" (the \n starts a new line).

labs(title = "Age and Gender\nat the Nobel Prize")

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + labs(title = "Age and Gender\nat the Nobel Prize") 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point() +
  labs(title = "Age and Gender\nat the Nobel Prize")

Exercise 2: a subtitle, and removing an axis label

Copy the chart from exercise 1. Add a subtitle reading "1901-2024", and remove the x axis label entirely (set it to NULL).

Both subtitle and x go inside the same labs() call as title.

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + labs(title = "Age and Gender\nat the Nobel Prize", subtitle = "1901-2024", x = NULL) 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point() +
  labs(title = "Age and Gender\nat the Nobel Prize",
       subtitle = "1901-2024",
       x = NULL)

Exercise 3: a preset theme

Copy the chart from exercise 1, and add the preset theme theme_light().

Preset themes are added just like any other layer: + theme_light().

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + theme_light() 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point() +
  theme_light()

Exercise 4: rotating axis text

df (from exercise 1’s setup) can also be drawn as a bar chart of n by category. Some of these category names (“Physiology or Medicine”, “Economic Sciences”) are too long to sit comfortably on the x axis. Add a theme() layer that rotates the x axis text (axis.text.x) by 45 degrees, with hjust and vjust both set to 1.

All three values mentioned in the instructions go inside the same element_text().

df |> ggplot(aes(x = category, y = n)) + geom_col() + theme(axis.text.x = element_text(angle = 45, hjust = 1, vjust = 1)) 
df |>
  ggplot(aes(x = category, y = n)) +
  geom_col() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1, vjust = 1))

Exercise 5: labelling every point

Copy the chart from exercise 1, and add a geom_text() layer that labels every point with its category.

geom_text(aes(label = category), size = 3)

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + geom_text(aes(label = category), size = 3) + labs(title = "Age and Gender\nat the Nobel Prize") 
df |>

  geom_text(aes(label = category), size = 3) +
  labs(title = "Age and Gender\nat the Nobel Prize")

Exercise 6: labelling a chosen few

df_text is df filtered to just Peace and Physics. Copy the chart from exercise 1, and add a geom_text() layer that labels only these two categories. You’ll need to set data = df_text inside geom_text(), as well as the label aesthetic.

data = df_text, and label = category.

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + geom_text(data = df_text, aes(label = category), size = 4) + labs(title = "Age and Gender\nat the Nobel Prize") 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point() +
  geom_text(data = df_text, aes(label = category), size = 4) +
  labs(title = "Age and Gender\nat the Nobel Prize")

Exercise 7: annotate() with text and a curve

Copy the chart from exercise 1. Add an annotate() layer with geom = 'text', at x = 56, y = 19, labelled "Peace". Then add a second annotate() layer with geom = 'curve', running from x = 56, y = 18.3 to xend = 60.8, yend = 17.1, with an arrow = arrow(type = 'closed', length = unit(2, 'mm')).

The first annotate() needs geom = 'text' and label = "Peace". The second needs geom = 'curve', xend = 60.8, and yend = 17.1.

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + annotate(geom = 'text', x = 56, y = 19, label = "Peace") + annotate(geom = 'curve', x = 56, y = 18.3, xend = 60.8, yend = 17.1, arrow = arrow(type = 'closed', length = unit(2, 'mm'))) 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point() +
  annotate(geom = 'text', x = 56, y = 19, label = "Peace") +
  annotate(geom = 'curve', x = 56, y = 18.3, xend = 60.8, yend = 17.1,
           arrow = arrow(type = 'closed', length = unit(2, 'mm')))

Exercise 8: annotate() with a rectangle

nobel_by_year is a line chart of the number of laureates (n) awarded per year. Add an annotate() layer with geom = 'rect', covering xmin = 1939 to xmax = 1946, from ymin = 0 to ymax = Inf, with alpha = .5. (This is the gap in the early 1940s when no prizes were awarded, because of the Second World War.)

annotate(geom = 'rect', xmin = 1939, xmax = 1946, ymin = 0, ymax = Inf, alpha = .5)

nobel_by_year |> ggplot(aes(x = award_year, y = n)) + geom_line() + annotate(geom = 'rect', xmin = 1939, xmax = 1946, ymin = 0, ymax = Inf, alpha = .5) 
nobel_by_year |>
  ggplot(aes(x = award_year, y = n)) +
  geom_line() +
  annotate(geom = 'rect', xmin = 1939, xmax = 1946, ymin = 0, ymax = Inf, alpha = .5)

Stretch exercise 9: pasted-together labels

df_text2 is df filtered to Peace and Literature, with a new column category_pct, pasting together the category name, " (", the rounded pct_female, and "%)" (with no separator between them). Add a geom_text() layer using df_text2, labelling each point with category_pct, coloured fixed black (not mapped).

data = df_text2, label = category_pct, and color = "black" (fixed, so outside aes()).

df |> ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) + geom_point() + geom_text(data = df_text2, aes(label = category_pct), size = 4, color = "black") + labs(title = "Age and Gender\nat the Nobel Prize") 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n, color = category)) +
  geom_point() +
  geom_text(data = df_text2, aes(label = category_pct), size = 4, color = "black") +
  labs(title = "Age and Gender\nat the Nobel Prize")

Stretch exercise 10: highlighting with colour

df_highlight is df filtered to just Peace, Literature, and Economic Sciences. Build a scatterplot of df (x = avg_age, y = pct_female, size = n), with all points coloured fixed 'gray50' and alpha = .8. Then add a second geom_point() layer using df_highlight, coloured fixed 'red', to make those three categories stand out.

The first geom_point() uses df (from the pipe) and color = 'gray50'. The second needs data = df_highlight and color = 'red'.

df |> ggplot(aes(x = avg_age, y = pct_female, size = n)) + geom_point(color = 'gray50', alpha = .8) + geom_point(data = df_highlight, color = 'red') 
df |>
  ggplot(aes(x = avg_age, y = pct_female, size = n)) +
  geom_point(color = 'gray50', alpha = .8) +
  geom_point(data = df_highlight, color = 'red')
