Data Visualisation 3: Practice Exercises

titles, themes, and annotations

These exercises practise titles, themes, and annotations from the Data Visualisation 3 part of the course book, using gapminder_df.

Like the other ggplot2 exercises, these are checked by comparing your code to a model solution, so the feedback will point you to a specific part of your code to fix.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: adding a title

Starting from the chart below, add a title reading "GDP and Life\nExpectancy" (the \n starts a new line).

labs(title = "GDP and Life\nExpectancy")

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + labs(title = "GDP and Life\nExpectancy") 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  labs(title = "GDP and Life\nExpectancy")

Exercise 2: a subtitle, and removing an axis label

Copy the chart from exercise 1. Add a subtitle reading "2007", and remove the x axis label entirely (set it to NULL).

Both subtitle and x go inside the same labs() call as title.

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + labs(title = "GDP and Life\nExpectancy", subtitle = "2007", x = NULL) 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  labs(title = "GDP and Life\nExpectancy",
       subtitle = "2007",
       x = NULL)

Exercise 3: a preset theme

Copy the chart from exercise 1, and add the preset theme theme_light().

Preset themes are added just like any other layer: + theme_light().

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + theme_light() 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  theme_light()

Exercise 4: rotating axis text

americas_df is a bar chart of gdpPercap by country. The country names overlap. Add a theme() layer that rotates the x axis text (axis.text.x) by 45 degrees, with hjust and vjust both set to 1.

All three values mentioned in the instructions go inside the same element_text().

americas_df |> ggplot(aes(x = country, y = gdpPercap)) + geom_col() + theme(axis.text.x = element_text(angle = 45, hjust = 1, vjust = 1)) 
americas_df |>
  ggplot(aes(x = country, y = gdpPercap)) +
  geom_col() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1, vjust = 1))

Exercise 5: labelling every point

Copy the chart from exercise 1, and add a geom_text() layer that labels every point with its country. (You’ll see why this is a bad idea for a chart this crowded - that’s the point of the next exercise!)

geom_text(aes(label = country), size = 3)

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + geom_text(aes(label = country), size = 3) + labs(title = "GDP and Life\nExpectancy") 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  geom_text(aes(label = country), size = 3) +
  labs(title = "GDP and Life\nExpectancy")

Exercise 6: labelling a chosen few

df_text is df filtered to just Ireland and Iceland. Copy the chart from exercise 1, and add a geom_text() layer that labels only these two countries. You’ll need to set data = df_text inside geom_text(), as well as the label aesthetic.

data = df_text, and label = country.

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + geom_text(data = df_text, aes(label = country), size = 4) + labs(title = "GDP and Life\nExpectancy") 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  geom_text(data = df_text, aes(label = country), size = 4) +
  labs(title = "GDP and Life\nExpectancy")

Exercise 7: annotate() with text and a curve

Copy the chart from exercise 1. Add an annotate() layer with geom = 'text', at x = 76, y = 45000, labelled "Netherlands". Then add a second annotate() layer with geom = 'curve', running from x = 76, y = 44000 to xend = 79.76, yend = 36797, with an arrow = arrow(type = 'closed', length = unit(2, 'mm')).

The first annotate() needs geom = 'text' and label = "Netherlands". The second needs geom = 'curve', xend = 79.76, and yend = 36797.

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + annotate(geom = 'text', x = 76, y = 45000, label = "Netherlands") + annotate(geom = 'curve', x = 76, y = 44000, xend = 79.76, yend = 36797, arrow = arrow(type = 'closed', length = unit(2, 'mm'))) 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  annotate(geom = 'text', x = 76, y = 45000, label = "Netherlands") +
  annotate(geom = 'curve', x = 76, y = 44000, xend = 79.76, yend = 36797,
           arrow = arrow(type = 'closed', length = unit(2, 'mm')))

Exercise 8: annotate() with a rectangle

western_europe_df is a line chart of gdpPercap over time for five countries. Add an annotate() layer with geom = 'rect', covering xmin = 1960 to xmax = 1980, from ymin = 0 to ymax = Inf, with alpha = .5.

annotate(geom = 'rect', xmin = 1960, xmax = 1980, ymin = 0, ymax = Inf, alpha = .5)

western_europe_df |> ggplot(aes(x = year, y = gdpPercap, color = country)) + geom_line() + annotate(geom = 'rect', xmin = 1960, xmax = 1980, ymin = 0, ymax = Inf, alpha = .5) 
western_europe_df |>
  ggplot(aes(x = year, y = gdpPercap, color = country)) +
  geom_line() +
  annotate(geom = 'rect', xmin = 1960, xmax = 1980, ymin = 0, ymax = Inf, alpha = .5)

Stretch exercise 9: pasted-together labels

df_text2 is df filtered to Ireland and Iceland, with a new column country_gdp, pasting together the country name, " (", the rounded gdpPercap, and ")" (with no separator between them). Add a geom_text() layer using df_text2, labelling each point with country_gdp, coloured fixed black (not mapped).

data = df_text2, label = country_gdp, and color = "black" (fixed, so outside aes()).

df |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) + geom_point() + geom_text(data = df_text2, aes(label = country_gdp), size = 4, color = "black") + labs(title = "GDP and Life\nExpectancy") 
df |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions, color = continent)) +
  geom_point() +
  geom_text(data = df_text2, aes(label = country_gdp), size = 4, color = "black") +
  labs(title = "GDP and Life\nExpectancy")

Stretch exercise 10: highlighting with colour

df_europe is df filtered to Europe. df_highlight is df_europe filtered to just Ireland, the Netherlands, and France. Build a scatterplot of df_europe (x = lifeExp, y = gdpPercap, size = pop_millions), with all points coloured fixed 'gray50' and alpha = .8. Then add a second geom_point() layer using df_highlight, coloured fixed 'red', to make those three countries stand out.

The first geom_point() uses df_europe (from the pipe) and color = 'gray50'. The second needs data = df_highlight and color = 'red'.

df_europe |> ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions)) + geom_point(color = 'gray50', alpha = .8) + geom_point(data = df_highlight, color = 'red') 
df_europe |>
  ggplot(aes(x = lifeExp, y = gdpPercap, size = pop_millions)) +
  geom_point(color = 'gray50', alpha = .8) +
  geom_point(data = df_highlight, color = 'red')
