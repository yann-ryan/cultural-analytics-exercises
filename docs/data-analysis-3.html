joins and tidying data

These exercises practise left_join() and pivot_longer() from the Data Analysis 3 part of the course book. They also give you a chance to combine these with everything else you’ve learned so far - select(), filter(), mutate(), arrange(), group_by(), and summarise().

Exercise 1: left_join()

Join titanic_df with locations_df, matching the embarked column in titanic_df to the code column in locations_df.

left_join(locations_df, by = c('embarked' = 'code')). The column names differ between the two datasets, so you need to say which matches which.

titanic_df |> left_join(locations_df, by = c('embarked' = 'code')) 
titanic_df |> left_join(locations_df, by = c('embarked' = 'code'))

Exercise 2: join, then select

Do the same join as before, then keep only the name, embarked, location_name, and country columns.

First left_join() as in exercise 1, then pipe into select() with the four column names.

titanic_df |> left_join(locations_df, by = c('embarked' = 'code')) |> select(name, embarked, location_name, country) 
titanic_df |>
  left_join(locations_df, by = c('embarked' = 'code')) |>
  select(name, embarked, location_name, country)

Exercise 3: join, then filter

Join titanic_df to locations_df as before, then keep only the passengers who embarked in France.

Join first, then filter(country == 'France'). Notice you’re filtering on a column that only exists after the join.

titanic_df |> left_join(locations_df, by = c('embarked' = 'code')) |> filter(country == 'France') 
titanic_df |>
  left_join(locations_df, by = c('embarked' = 'code')) |>
  filter(country == 'France')

Exercise 4: join, group, and count

Join titanic_df to locations_df, then calculate the total number of passengers (total) for each country.

Join, then group_by(country), then summarise(total = n()).

titanic_df |> left_join(locations_df, by = c('embarked' = 'code')) |> group_by(country) |> summarise(total = n()) 
titanic_df |>
  left_join(locations_df, by = c('embarked' = 'code')) |>
  group_by(country) |>
  summarise(total = n())

Exercise 5: join, group by two variables

Do the same again, but this time calculate the total number of passengers (total) for each combination of country and sex.

Same as exercise 4, but group_by() two columns this time: country and sex.

titanic_df |> left_join(locations_df, by = c('embarked' = 'code')) |> group_by(country, sex) |> summarise(total = n()) 
titanic_df |>
  left_join(locations_df, by = c('embarked' = 'code')) |>
  group_by(country, sex) |>
  summarise(total = n())

Exercise 6: pivot_longer()

gapminder_population is a wide dataset: one row per European country, with a separate column for each year’s population. Reshape it into long format, so that each row is a single country-year observation. Call the new columns year and population.

pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population'). Columns 2 to 13 are all the year columns - column 1 is country.

gapminder_population |> pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') 
gapminder_population |> pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population')

Exercise 7: reshape, then filter

Reshape gapminder_population as before, then keep only the rows for the year 2007.

Note

After pivot_longer(), the new year column contains text, not numbers (because the original column headings were text). Good practice is to filter using "2007", in quotation marks - R will actually convert a bare 2007 for you when comparing it to a text column, but it’s worth knowing which type you’re working with, since not every function is this forgiving.

Pivot first, then filter(year == "2007").

gapminder_population |> pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') |> filter(year == "2007") 
gapminder_population |>
  pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') |>
  filter(year == "2007")

Exercise 8: reshape, then arrange

Reshape gapminder_population as before, then sort the result by population, from highest to lowest.

Pivot first, then arrange(-population).

gapminder_population |> pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') |> arrange(-population) 
gapminder_population |>
  pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') |>
  arrange(-population)

Stretch exercise 9: reshape, group, and summarise

Reshape gapminder_population, then calculate the average population (call it avg_pop) for each country, across all the years in the data.

Three steps: pivot_longer(), then group_by(country), then summarise(avg_pop = mean(population, na.rm = TRUE)).

gapminder_population |> pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') |> group_by(country) |> summarise(avg_pop = mean(population, na.rm = TRUE)) 
gapminder_population |>
  pivot_longer(cols = 2:13, names_to = 'year', values_to = 'population') |>
  group_by(country) |>
  summarise(avg_pop = mean(population, na.rm = TRUE))

Stretch exercise 10: join, mutate, and arrange

Join titanic_df to locations_df as in the earlier exercises. Then create a new column called name_country, which pastes together the passenger’s name and their country, separated by " - " (for example: "Allen, Miss. Elisabeth Walton - United Kingdom"). Finally, sort the result by country.

Join, then mutate(name_country = paste(name, "-", country)), then arrange(country). Remember paste() puts spaces between its pieces by default, so paste(name, "-", country) already gives you "name - country".

titanic_df |> left_join(locations_df, by = c('embarked' = 'code')) |> mutate(name_country = paste(name, "-", country)) |> arrange(country) 
titanic_df |>
  left_join(locations_df, by = c('embarked' = 'code')) |>
  mutate(name_country = paste(name, "-", country)) |>
  arrange(country)
