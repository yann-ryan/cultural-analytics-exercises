Data Visualisation 2: Practice Exercises

position and colour scales

These exercises practise position and colour scales from the Data Visualisation 2 part of the course book, using the gapminder_df dataset.

Like the ggplot2 exercises before these, they’re checked by comparing your code to a model solution, so the feedback will point you to a specific part of your code to fix.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: setting limits

Starting from the chart below, add a scale_x_continuous() layer that limits the x axis to the years 1980 to 2000.

scale_x_continuous(limits = c(1980, 2000))

netherlands_df |> ggplot(aes(x = year, y = gdpPercap)) + geom_line() + scale_x_continuous(limits = c(1980, 2000)) 
netherlands_df |>
  ggplot(aes(x = year, y = gdpPercap)) +
  geom_line() +
  scale_x_continuous(limits = c(1980, 2000))

Exercise 2: setting breaks

Copy the chart from exercise 1, and add breaks to the same scale_x_continuous(), so the axis only shows ticks at 1980, 1990, and 2000.

breaks takes a vector: c(1980, 1990, 2000).

netherlands_df |> ggplot(aes(x = year, y = gdpPercap)) + geom_line() + scale_x_continuous(limits = c(1980, 2000), breaks = c(1980, 1990, 2000)) 
netherlands_df |>
  ggplot(aes(x = year, y = gdpPercap)) +
  geom_line() +
  scale_x_continuous(limits = c(1980, 2000),
                      breaks = c(1980, 1990, 2000))

Exercise 3: reorder()

americas_df contains a handful of South American countries’ data for 2002. Build a bar chart of gdpPercap by country, with the bars ordered from highest to lowest.

reorder(country, desc(gdpPercap)) orders the bars from highest to lowest. The geom is geom_col().

americas_df |> ggplot(aes(x = reorder(country, desc(gdpPercap)), y = gdpPercap)) + geom_col() 
americas_df |>
  ggplot(aes(x = reorder(country, desc(gdpPercap)), y = gdpPercap)) +
  geom_col()

Exercise 4: reorder() with coord_flip()

Copy the chart from exercise 3, but this time order the bars so that after you add coord_flip(), the highest value appears at the top. (Hint: think about whether you still need desc() once the chart is flipped.)

Without desc() this time - coord_flip() reverses the vertical order, so removing desc() puts the highest value at the top.

americas_df |> ggplot(aes(x = reorder(country, gdpPercap), y = gdpPercap)) + geom_col() + coord_flip() 
americas_df |>
  ggplot(aes(x = reorder(country, gdpPercap), y = gdpPercap)) +
  geom_col() +
  coord_flip()

Exercise 5: a continuous colour scale

Using sample_for_bar_chart, build a bar chart with country on the x axis, gdpPercap on the y axis, and lifeExp mapped to fill. Then add scale_fill_viridis_c() as an extra layer.

lifeExp is numeric, so it needs a continuous scale: scale_fill_viridis_c().

sample_for_bar_chart |> ggplot(aes(x = country, y = gdpPercap, fill = lifeExp)) + geom_col() + scale_fill_viridis_c() 
sample_for_bar_chart |>
  ggplot(aes(x = country, y = gdpPercap, fill = lifeExp)) +
  geom_col() +
  scale_fill_viridis_c()

Exercise 6: a discrete colour palette

Copy the chart from exercise 5, but map continent to fill instead, and use scale_fill_brewer() with the palette 'Set2'.

scale_fill_brewer(palette = 'Set2'). continent is categorical, so it gets a discrete scale.

sample_for_bar_chart |> ggplot(aes(x = country, y = gdpPercap, fill = continent)) + geom_col() + scale_fill_brewer(palette = 'Set2') 
sample_for_bar_chart |>
  ggplot(aes(x = country, y = gdpPercap, fill = continent)) +
  geom_col() +
  scale_fill_brewer(palette = 'Set2')

Exercise 7: a custom gradient

Copy the lifeExp-filled chart from exercise 5 again (without scale_fill_viridis_c() this time), and instead add your own two-colour gradient scale, running from 'firebrick' (low) to 'gold' (high).

scale_fill_gradient(low = 'firebrick', high = 'gold')

sample_for_bar_chart |> ggplot(aes(x = country, y = gdpPercap, fill = lifeExp)) + geom_col() + scale_fill_gradient(low = 'firebrick', high = 'gold') 
sample_for_bar_chart |>
  ggplot(aes(x = country, y = gdpPercap, fill = lifeExp)) +

Exercise 8: scale_fill_manual()

Copy the continent-filled chart from exercise 6 (without scale_fill_brewer() this time). South America, Europe, and Asia are the only continents in this data. Set their fill colours manually and in that order, to 'firebrick', 'forestgreen', and 'orange'.

scale_fill_manual(values = c('firebrick', 'forestgreen', 'orange'))

sample_for_bar_chart |> ggplot(aes(x = country, y = gdpPercap, fill = continent)) + geom_col() + scale_fill_manual(values = c('firebrick', 'forestgreen', 'orange')) 
sample_for_bar_chart |>
  ggplot(aes(x = country, y = gdpPercap, fill = continent)) +
  geom_col() +
  scale_fill_manual(values = c('firebrick', 'forestgreen', 'orange'))

Stretch exercise 9: combining several scale options

Copy the chart from exercise 2. Add two more things to the same scale_x_continuous(): minor_breaks, set to every single year from 1980 to 2000 (1980:2000), and labels, set to c('Year 1', 'Year 2', 'Year 3').

Four arguments to scale_x_continuous() in total now: limits, breaks, minor_breaks, and labels.

netherlands_df |> ggplot(aes(x = year, y = gdpPercap)) + geom_line() + scale_x_continuous(limits = c(1980, 2000), breaks = c(1980, 1990, 2000), minor_breaks = 1980:2000, labels = c('Year 1', 'Year 2', 'Year 3')) 
netherlands_df |>
  ggplot(aes(x = year, y = gdpPercap)) +
  geom_line() +
  scale_x_continuous(limits = c(1980, 2000),
                      breaks = c(1980, 1990, 2000),
                      minor_breaks = 1980:2000,
                      labels = c('Year 1', 'Year 2', 'Year 3'))
