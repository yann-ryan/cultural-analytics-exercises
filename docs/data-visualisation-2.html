Data Visualisation 2: Practice Exercises

position and colour scales

These exercises practise position and colour scales from the Data Visualisation 2 part of the course book, using the Nobel Prize dataset.

Like the ggplot2 exercises before these, they’re checked by comparing your code to a model solution, so the feedback will point you to a specific part of your code to fix.

The last two exercises are a bit more of a stretch - come back to them once you’re comfortable with the rest.

Exercise 1: setting limits

Starting from the chart below, add a scale_x_continuous() layer that limits the x axis to the years 1980 to 2000.

scale_x_continuous(limits = c(1980, 2000))

nobel_by_year |> ggplot(aes(x = award_year, y = n)) + geom_line() + scale_x_continuous(limits = c(1980, 2000)) 
nobel_by_year |>
  ggplot(aes(x = award_year, y = n)) +
  geom_line() +
  scale_x_continuous(limits = c(1980, 2000))

Exercise 2: setting breaks

Copy the chart from exercise 1, and add breaks to the same scale_x_continuous(), so the axis only shows ticks at 1980, 1990, and 2000.

breaks takes a vector: c(1980, 1990, 2000).

nobel_by_year |> ggplot(aes(x = award_year, y = n)) + geom_line() + scale_x_continuous(limits = c(1980, 2000), breaks = c(1980, 1990, 2000)) 
nobel_by_year |>
  ggplot(aes(x = award_year, y = n)) +
  geom_line() +
  scale_x_continuous(limits = c(1980, 2000),
                      breaks = c(1980, 1990, 2000))

Exercise 3: reorder()

nobel_summary has one row per prize category. Build a bar chart of n (the number of laureates) by category, with the bars ordered from highest to lowest.

reorder(category, desc(n)) orders the bars from highest to lowest. The geom is geom_col().

nobel_summary |> ggplot(aes(x = reorder(category, desc(n)), y = n)) + geom_col() 
nobel_summary |>
  ggplot(aes(x = reorder(category, desc(n)), y = n)) +
  geom_col()

Exercise 4: reorder() with coord_flip()

Copy the chart from exercise 3, but this time order the bars so that after you add coord_flip(), the highest value appears at the top. (Hint: think about whether you still need desc() once the chart is flipped.)

Without desc() this time - coord_flip() reverses the vertical order, so removing desc() puts the highest value at the top.

nobel_summary |> ggplot(aes(x = reorder(category, n), y = n)) + geom_col() + coord_flip() 
nobel_summary |>
  ggplot(aes(x = reorder(category, n), y = n)) +
  geom_col() +
  coord_flip()

Exercise 5: a continuous colour scale

Using nobel_summary, build a bar chart with category on the x axis, n on the y axis, and pct_female mapped to fill. Then add scale_fill_viridis_c() as an extra layer.

pct_female is numeric, so it needs a continuous scale: scale_fill_viridis_c().

nobel_summary |> ggplot(aes(x = category, y = n, fill = pct_female)) + geom_col() + scale_fill_viridis_c() 
nobel_summary |>
  ggplot(aes(x = category, y = n, fill = pct_female)) +
  geom_col() +
  scale_fill_viridis_c()

Exercise 6: a discrete colour palette

Copy the chart from exercise 5, but map category to fill as well (instead of pct_female), and use scale_fill_brewer() with the palette 'Set2'.

scale_fill_brewer(palette = 'Set2'). category is categorical, so it gets a discrete scale.

nobel_summary |> ggplot(aes(x = category, y = n, fill = category)) + geom_col() + scale_fill_brewer(palette = 'Set2') 
nobel_summary |>
  ggplot(aes(x = category, y = n, fill = category)) +
  geom_col() +
  scale_fill_brewer(palette = 'Set2')

Exercise 7: a custom gradient

Copy the pct_female-filled chart from exercise 5 again (without scale_fill_viridis_c() this time), and instead add your own two-colour gradient scale, running from 'firebrick' (low) to 'gold' (high).

scale_fill_gradient(low = 'firebrick', high = 'gold')

nobel_summary |> ggplot(aes(x = category, y = n, fill = pct_female)) + geom_col() + scale_fill_gradient(low = 'firebrick', high = 'gold') 
nobel_summary |>
  ggplot(aes(x = category, y = n, fill = pct_female)) +
  geom_col() +
  scale_fill_gradient(low = 'firebrick', high = 'gold')

Exercise 8: scale_fill_manual()

Copy the category-filled chart from exercise 6 (without scale_fill_brewer() this time). There are six categories, in alphabetical order: Chemistry, Economic Sciences, Literature, Peace, Physics, and Physiology or Medicine. Set their fill colours manually and in that order, to 'firebrick', 'forestgreen', 'orange', 'steelblue', 'goldenrod', and 'orchid'.

scale_fill_manual(values = c('firebrick', 'forestgreen', 'orange', 'steelblue', 'goldenrod', 'orchid'))

nobel_summary |> ggplot(aes(x = category, y = n, fill = category)) + geom_col() + scale_fill_manual(values = c('firebrick', 'forestgreen', 'orange', 'steelblue', 'goldenrod', 'orchid')) 
nobel_summary |>
  ggplot(aes(x = category, y = n, fill = category)) +
  geom_col() +
  scale_fill_manual(values = c('firebrick', 'forestgreen', 'orange', 'steelblue', 'goldenrod', 'orchid'))

Stretch exercise 9: combining several scale options

Copy the chart from exercise 2. Add two more things to the same scale_x_continuous(): minor_breaks, set to every single year from 1980 to 2000 (1980:2000), and labels, set to c('Year 1', 'Year 2', 'Year 3').

Four arguments to scale_x_continuous() in total now: limits, breaks, minor_breaks, and labels.

nobel_by_year |> ggplot(aes(x = award_year, y = n)) + geom_line() + scale_x_continuous(limits = c(1980, 2000), breaks = c(1980, 1990, 2000), minor_breaks = 1980:2000, labels = c('Year 1', 'Year 2', 'Year 3')) 
nobel_by_year |>
  ggplot(aes(x = award_year, y = n)) +
  geom_line() +
  scale_x_continuous(limits = c(1980, 2000),
                      breaks = c(1980, 1990, 2000),
                      minor_breaks = 1980:2000,
                      labels = c('Year 1', 'Year 2', 'Year 3'))

Stretch exercise 10: a diverging colour scale

Copy the pct_female-filled chart from exercise 5 (without scale_fill_viridis_c()). This time use a diverging gradient scale: 'firebrick' for low, 'white' for mid, 'gold' for high, with the midpoint set to 10.

scale_fill_gradient2(low = 'firebrick', mid = 'white', high = 'gold', midpoint = 10)
